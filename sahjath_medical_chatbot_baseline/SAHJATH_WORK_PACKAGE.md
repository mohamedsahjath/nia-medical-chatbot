# Sahjath Work Package — Baseline Medical Chatbot

## Implemented components

1. Medical knowledge-base dataset with questions, answers, intents, keywords and trusted source links.
2. NLP preprocessing: lowercasing, tokenization, stop-word removal and word normalization.
3. TF-IDF vectorization to convert text into numerical features.
4. Logistic Regression for healthcare intent classification.
5. Cosine-similarity medical knowledge retrieval.
6. Emergency symptom detection and Sri Lanka 1990 ambulance guidance.
7. Streamlit chatbot integration.
8. Baseline evaluation and automated system checks.
